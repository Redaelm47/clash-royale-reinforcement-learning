# data/

All data is ignored by git, only the READMEs are tracked.

- `replays/`: play-by-play IL_Replay games (card, position, timing), see `replays/README.md`.
- `crforge_bc/`: imitation rows for the 2.6 side, written by `sim/il_to_crforge.py`.
- `tables/`: game data tables (card stats, etc.), to create locally if needed. Never commit them.
